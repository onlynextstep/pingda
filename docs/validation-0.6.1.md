# 0.6.1 验证记录

日期：2026-10-08。

## 自动测试

九个测试项目通过：Update、Settings、Core、Log、App、Windows、Studio、Drag、SceneManager。WPF 假硬件界面测试 170/170 通过。

更新测试覆盖版本比较、HTTPS 地址、跳转、防降级、长度与 SHA256 校验、取消清理。窗口测试覆盖设置面板单实例、不禁用主窗口、收起后关闭和再次打开。

修复回归覆盖故障退出不等待阻塞的退出回调、重复启动激活已有实例、错误提示不锁住主窗口且不重复弹出。

## 安装器

独立目录验证通过运行锁阻止安装、全新安装、重装、模拟激活失败回退、额外文件保护和卸载保留配置。安装后通过自包含文件与资源完整性验证；升级前后的预设和设置逐项哈希一致。

## 实机检查

仅 4K 屏横屏 → 竖屏 → 横屏的切换、显示器身份与布局回读通过。最终恢复横屏。设置面板打开时可以收起软件；再次启动会唤回原进程的主窗口，不遗留设置窗口。

## 公开更新端点

0.6.0 可发现 0.6.1；同版本不会重复提示。更新下载必须通过长度与 SHA256 校验。修复构建沿用 0.6.1 版本号，已安装早期构建的用户需手动重新安装。

## 验证限制

上述检查不代表跨显卡、高刷新率与两屏/三屏切换全部兼容。安装包尚未进行发行者代码签名。

商店 MSIX 已完成开发身份打包验证，未签名、未提交审核。正式身份下的启动任务、数据位置和独立恢复进程仍需验证。
