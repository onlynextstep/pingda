# 0.6.1 验证记录

日期：2026-10-07。

## 自动测试

构建入口通过九个测试项目：Update、Settings、Core、Log、App、Windows、Studio、Drag、SceneManager。

WPF假硬件界面测试：170/170。更新测试覆盖版本比较、HTTPS地址、跳转、防降级、长度/hash校验、取消清理。设置窗口测试覆盖不禁用主窗口、单实例、隐藏关闭和再次打开。

## 安装器

独立测试目录验证：运行锁阻止安装、新安装、自包含资源验证、同版本重装、模拟激活失败回退、额外文件保护、卸载与原配置哈希不变。额外验证 `/UPDATE` 等待主进程锁释放后继续安装。

## 公开更新端点

以0.6.0作为当前版本查询公开JSON，发现0.6.1；以0.6.1查询不再提示。使用生产UpdateService从GitHub公开下载实际EXE，经HTTPS跳转、长度与SHA256校验成功。

下载的EXE在开发者电脑完成安装，自包含清单验证通过，个人配置哈希不变；桌面和已有旧快捷方式改到新版入口，旧程序目录移入开发备份。

## 微软商店准备

Windows SDK makeappx成功生成开发身份的未签名MSIX。此结果只验证包结构，不表示正式身份、签名、安装后行为或商店认证通过。

## 尚未验证

本轮没有真实切换显示器，不能据此宣布跨显卡、高刷新率与两屏/三屏切换全部兼容。商店启动任务、包数据位置和独立guardian行为需在正式包身份下继续验证。
