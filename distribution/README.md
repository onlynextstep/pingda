# 屏搭 0.6.1 · 内测版

适用于 Windows 10 / 11 x64。安装包为 `PingDa-0.6.1-Setup.exe`，包含运行时。

本版本新增更新检查，修复重复渲染错误弹窗和设置面板阻塞主窗口。免费开源版与计划中的微软商店支持版功能一致。

## 使用与升级

关闭主窗口收起到托盘，托盘右键可退出。升级保留预设、屏幕名称和快捷键。安装器使用当前用户的 Programs\PingDa 目录；个人配置继续使用 LocalAppData\PingXu，兼容历史版本。

软件内下载更新后，选择“退出并安装”。旧0.6.0及更早版本需要先手动安装包含更新检查的新版本。

卸载保留个人配置。屏幕停用只停止输出，不切断电源。

## 内测范围

当前支持本地扩展桌面，最多管理六块已连接屏幕。不调整HDR、Windows缩放、亮度、ICC或音频设备。不同显卡、接口、显示器和高刷新率组合仍需验证。

切屏失败且恢复状态未知时，先在Windows显示设置中检查画面，再进入屏搭“检查恢复保护”。独立恢复进程不能保证在断电、驱动故障或进程被强制结束时完成恢复。

更新检查访问公开发布信息，不上传设备配置。安装包SHA256用于确认下载完整性，不代替发行者签名。

在GitHub Issues反馈操作步骤和错误。诊断信息由用户选择导出，公开前请检查内容。
